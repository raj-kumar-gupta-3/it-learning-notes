# cat command

`cat` shows the text inside a file.

## Commands I practiced

| Command | What it does |
|---------|--------------|
| `cat file` | Shows the file |
| `cat file1 file2` | Shows two files together |
| `cat -n file` | Shows line numbers |
| `cat > file` | Creates a file (replaces old text) |
| `cat >> file` | Adds text at the end (keeps old text) |

## Important

- `>` replaces the old text.
- `>>` keeps the old text and adds new text.
- Do not use `cat` on photos or PDF files. The terminal shows strange letters.
