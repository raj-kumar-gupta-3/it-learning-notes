# Computer Fundamentals

## What is a Computer?

A computer is an electronic machine that accepts data, processes it, stores it and gives results.

## 1. Hardware

Hardware means the physical parts of a computer that we can touch.

Examples:
- CPU
- RAM
- SSD
- Motherboard
- Keyboard
- Monitor

## 2. Software

Software means programs that tell a computer what to do.

Examples:
- Windows
- Linux
- Kali Linux
- Firefox
- Python

## 3. CPU (Central Processing Unit)

CPU is an important part of a computer.

It executes instructions and performs calculations.

It is often called the brain of the computer.

## 4. RAM (Random Access Memory)

RAM is temporary memory.

It stores data that running programs need.

When the computer is turned off, RAM normally loses its data.

## 5. SSD (Solid State Drive)

SSD is used to store files, programs and the operating system.

It keeps data even when the computer is turned off.

## 6. Motherboard

The motherboard is the main circuit board of a computer.

It connects different hardware components.

## 7. Input and Output

Input devices send data to a computer.

Examples:
- Keyboard
- Mouse
- Microphone

Output devices show the results.

Examples:
- Monitor
- Printer
- Speakers

## What I Learned

- A computer accepts and processes data.
- Hardware means physical computer parts.
- Software means programs and instructions.
- CPU executes instructions.
- RAM stores temporary data.
- SSD stores data permanently.
- Motherboard connects computer components.

## Practical Commands

```bash
lscpu
free -h
lsblk
uname -r
```

These commands help us check CPU, memory, storage and Linux kernel information.
